# AI 학습과 비교 계획

## 이미 실행할 수 있는 것

1. 입고 목록·카메라 조건·규칙을 담은 에피소드 생성.
2. `PackingEnv`에서 현재 박스를 순차 배치하고 상태·재고·지지 하중 갱신.
3. 관측 입력만 사용해 후보별 제한된 미래 탐색 점수 생성.
4. NumPy 신경망으로 후보 점수 회귀. 정규화는 train에서만 계산하고 학습 epoch는 validation MSE로 고른 뒤 test를 한 번 평가.
5. 같은 시험 재고·순서의 카메라 4종을 기준 탐욕 정책과 신경망 정책으로 각각 실행.

```bash
python -m pacdata.evaluate --dataset data/generated --model data/model/ranker_model.json --families 12 --out data/paired_comparison.json
```

결과는 완료율, 적재 개수·부피, 실제 평균 확인 미리보기 수, 결정 시간입니다. 생성/특징/추론 시간을 재며 로봇 동작시간은 아닙니다. `NO_VALID_SEARCH_CANDIDATE`는 구현된 유한 후보 생성기에서 후보를 찾지 못했다는 뜻이고 전체 기하학적 배치 불가능의 증명은 아닙니다.

## 왜 입고 목록만 더 많이 만들지 않았나

배포한 예제 모델은 시험 상태의 교사 최고 후보 일치율(동점 포함) 약 16.7%, 평균 교사 점수 손실 약 0.0361입니다. 제한된 교사를 모방하는 초기 연결 예제이며 충분히 좋은 후보 선별 모델이라고 판단할 수준은 아닙니다. 함께 실행한 시험 가족 12개(카메라 4종 × 정책 2개 = 96회)에서도 카메라 확대에 따른 일관된 적재 개선을 확인했다고 주장하지 않습니다. 교사·후보 생성·특징·학습 목표를 개선하고 더 넓은 시험으로 검증하세요. 원본 보고서는 docs의 EXAMPLE_TRAINING_REPORT.json과 EXAMPLE_COMPARISON_REPORT.json에 있습니다.

입고 목록에는 ‘이 상태에서 어느 위치가 더 좋은가’라는 정답이 없습니다. 지금 팩은 실제 배치 중간 상태와 후보를 만든 뒤, 알고 있는 다음 순서와 수량을 보존한 미관측 미래를 시도해 후보 점수를 만듭니다. 이것이 점수/순위 모델의 표적입니다.

교사의 탐색과 후보 생성은 단순합니다. 학습 모델이 교사보다 실제 적재를 잘한다고 주장할 수 없습니다. 모델이 유망 후보를 먼저 추려 주도록 연결하고, 나중에 더 깊은 공통 평가로 최종 후보를 결정하는 방식이 권장되는 확장입니다.

## 비교를 구분하기

| 비교 | 확인할 효과 |
|---|---|
| 현재만 보는 P0 ↔ 관측된 미래를 보는 P1 | 다음 상자 정보의 효과 |
| P1 ↔ 미관측 재고까지 샘플링하는 P2 | 미래 불확실성 대비의 효과 |
| P2 ↔ 신경망으로 후보를 줄인 뒤 같은 P2로 평가하는 P3 | AI 후보 선별의 계산 효율·품질 |
| 같은 정책의 2/4/8/12 카메라 입력 | 탑뷰 관측 확장의 효과 |

현재 실행 가능한 비교 코드는 P0와 **학습 점수를 바로 사용하는 정책**입니다. 이를 최종 P3 구현이라고 부르지는 않습니다. P1/P2/P3 전체 비교와 로봇 검증은 팀 알고리즘 연결 후 추가하세요.

같은 그룹·시나리오의 4개 에피소드는 실제 입고 목록이 같습니다. 카메라 시야와 최대 추적 수를 함께 바꾸므로, 이 비교는 ‘카메라 관측 프로필 전체의 효과’입니다. 박스 개수 상한만의 효과를 분리하려면 시야 길이를 고정하고 상한만 변경하는 별도 프로필을 만들어야 합니다.

관측이 늘면 계산해야 할 미래도 늘 수 있습니다. 동일 결정 시간 한도·후보 상한을 적용한 실험과 충분한 계산 시간을 준 실험을 분리해 기록합니다. 기본 교사는 후보 8개·샘플 2개·깊이 12를 쓰는 오프라인 표적 생성기이며 실시간 목표 200 ms를 달성했다고 주장하지 않습니다.

## 다음에 학습 품질을 높이는 순서

1. 팀원의 후보 생성기로 교체하고 후보의 다양성을 늘립니다. 초기 버전은 바닥/상부 모서리 주변의 제한된 후보만 탐색합니다.
2. 교사 후보·미래 샘플·깊이를 늘리고 같은 상태에서 점수 안정성을 확인합니다. 샘플을 늘리는 것만으로 교사의 탐욕 정책 편향이 없어지지는 않습니다.
3. 다양한 행동 정책과 임의의 유효 배치로 중간 상태를 추가 수집합니다. 현재 상태 수집은 기준 탐욕과 교사 선택의 혼합입니다.
4. 측정된 실제 CCTV 검출·추적 결과와 현재 지점의 실측 치수·무게를 연결합니다. 실제 오차 분포와 가림의 시간 상관관계를 추정합니다.
5. 새 SKU·치수 범위·새 팔레트·센서 환경은 별도 시험으로 분리합니다.
6. 실제 로봇 경로·접근·파지·작업시간을 후보 평가에 추가합니다. 이 팩의 무게중심 균형 점수는 동적 안정성 검증을 대신하지 않습니다.

## 강화학습으로 넘어가기

`PackingEnv`에는 reset, PLACE, ROUTE_DAMAGE, REMEASURE, STOP, 상태 갱신·보상·종료가 있습니다. Gymnasium에 연결하려면 관측/행동 공간, reset 반환 `(observation, info)`, step의 `terminated`/`truncated` 분리, action mask와 예외 행동을 래퍼로 구현해야 합니다. 환경이 반복 실행된다는 이유만으로 현재 보상이 충분히 좋은 강화학습 목표라고 가정하지 않습니다.

현재 보상은 성공 적재 부피 비율, 재측정 비용, 후보 없음 종료 패널티의 개발 초안입니다. 무게중심·하중·추론 시간·실제 작업시간, 완성된 에피소드의 목표를 고려해 학습 목적과 맞춰야 합니다. 안전한 후보 마스크는 계속 별도로 적용합니다.
